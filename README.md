# 传纸条 · Slipping Notes

一个手绘 doodle 风格的小游戏：你是两个传纸条同学之间的中间人。

- **向左接**：左边同学把纸条丢过来，纸条到你头边的一瞬间按住屏幕转头才能接住。转头总时间有限，用完就被老师发现。
- **向右丢**：拿到纸条后长按蓄力，上滑调整角度，松手丢出去。只有落在收信同学的桌子上才算传到，掉地上、丢错桌都失败。每张纸条有持有时限。
- **老师随机出现**：出现前有 ❗ 预警，老师在场时转头或蓄力都会被抓，Game Over。
- **5 个关卡**越来越难，过关称号：能用的纸条人 → 靠谱的纸条侠 → 纸条转运中心 → 传奇纸条王 → 无敌纸条大帝。

## 运行

单文件 `index.html`，无依赖，直接用浏览器打开即可，手机竖屏体验最佳。支持触屏与鼠标。

## 调参

`index.html` 里的 `LEVELS` 数组控制每关的纸条数、同学数、转头时间、持有时限、老师出现频率和轨迹预览比例。
